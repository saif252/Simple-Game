# Simple Games

A collection of small, beginner-friendly console games built while learning programming fundamentals.

Each project focuses on core concepts like logic building, user input, control flow, and problem solving.

More games will be added over time.

---

## 🎮 Games Included

### Rock–Paper–Scissors
A classic game where the player competes against the computer by choosing Rock, Paper, or Scissors.

### Number Guessing Game
The computer selects a random number and the player tries to guess it.

### Snake
A simple console-based implementation of the classic snake game.

### Tic Tac Toe
A two-player or player-vs-computer implementation of Tic Tac Toe.

---

## Notes
- All games are console-based
- Written for learning and practice
- Focus on simplicity and clarity
